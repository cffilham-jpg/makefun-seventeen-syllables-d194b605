One haiku about debugging, in the 5-7-5 shape, for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

```
red tests at midnight
a single log line points home
it was a comma
```

`main.py` (Python 3.13, stdlib only) writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`).
